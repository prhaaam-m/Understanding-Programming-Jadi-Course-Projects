# Understanding-Programming-Jadi-Course-Projects
پروژه‌های دوره‌ی درک برنامه‌نویسی جادی در مکتب‌خونه


این ریپو برای پروژه‌های دوره‌ی درک برنامه‌نویسی جادی در سایت مکتب‌خونه ایجاد شده، سعی کردم تغییرات و خلاقیت‌هایی در هر کدوم ایجاد کنم. تقریبا برای همش مکانیزم خروج تعریف کردم یا تکرار مجدد برنامه، برای بعضی از برنامه‌ها با Pyinstaller فایل اجرایی ساختم و در پروژه تاس نوتبوک ژوپیتر رو هم برای دسترسی بهتر قرار دادم.
خوشحال میشم اگر تغییرات یا خلاقیت‌های دیگه‌ای برای بهبود و توسعه‌ی بیشتر برنامه‌ها دارید از این کدها استفاده کنید. یک پروژه فان و ساده که انجام دادنش حال میده :)
